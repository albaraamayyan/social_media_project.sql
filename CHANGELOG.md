# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-12
### Added
- Initial release of the Social Media Platform database schema.
- Core relational tables: `users`, `profiles`, `tweets`, and `follows`.
- Secure password hashing implementation using `BINARY(64)`.
- Automated business logic via Stored Procedures: `createAccount` and `User_Follow`.
- Comprehensive documentation and project structure.
- MIT License for open-source distribution.
